# Цели на жизнь — приложение для iPhone

Это веб-приложение. После установки оно живёт на экране «Домой» с собственной иконкой, открывается на весь экран и работает без интернета. Отметки хранятся на самом телефоне.

## Что в папке

- `index.html`, `style.css`, `app.js` — само приложение
- `sw.js` — офлайн-режим
- `manifest.webmanifest` и `icons/` — название и иконка

Стартовое состояние такое же, как на странице в Claude: 12 стран, 5 донаций.

## Установка через GitHub Pages (~5 минут)

1. Создай на GitHub публичный репозиторий, например `life-goals`.
2. Загрузи в него **содержимое** этой папки: Add file → Upload files. Файлы должны лежать в корне репозитория, без вложенной папки.
3. Открой Settings → Pages. В Source выбери Deploy from a branch, ветку `main` и папку `/ (root)`, нажми Save.
4. Через пару минут приложение откроется по адресу `https://<логин>.github.io/life-goals/`.
5. Открой этот адрес на айфоне в Safari → «Поделиться» → «На экран „Домой“».

Репозиторий будет публичным, но в нём лежит только список целей и стартовые счётчики. Твои отметки остаются на телефоне.

## Установка на свой сервер

Подойдёт любой веб-сервер, который отдаёт статику по HTTPS. Без HTTPS офлайн-режим не заработает, поэтому нужен домен с сертификатом. Пример для Caddy, который выпускает сертификат сам:

```
goals.example.com {
    root * /var/www/life-goals
    file_server
}
```

Скопируй файлы в `/var/www/life-goals/`, перезапусти Caddy и добавь адрес на экран «Домой» так же, как в шаге 5.

## Резервная копия

Внизу приложения есть кнопки «Сохранить копию» и «Восстановить из файла». Копия — это JSON-файл. Сохраняй её в «Файлы» или себе в мессенджер. Через неё же отметки переносятся на другое устройство.

Перед тем как удалить иконку с экрана «Домой», обязательно сохрани копию: iOS может стереть данные приложения вместе с ним.

## Как обновить приложение

1. Замени файлы на хостинге.
2. В начале `sw.js` увеличь версию кэша: например, `life-goals-v3` → `life-goals-v4`.
3. Открой приложение с интернетом, закрой и открой ещё раз — подтянется новая версия.

Отметки при обновлении не теряются.

## Важно

Приложение и страница в Claude между собой не синхронизируются. Отмечай цели в одном месте, чтобы не путаться.
